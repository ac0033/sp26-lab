# CS 61C · Spring 2026 Labs

UC Berkeley CS 61C 实验材料的个人 fork。当前目录包含 lab00–lab07，保留课程提供的代码、测试和脚本；文件存在不等于所有练习都已完成或通过测试。

## 目录

| 入口 | 内容 |
|---|---|
| [lab00](lab00/) | 环境初始化、SSH 与 Python 入门脚本 |
| [lab01](lab01/) | C：指针、数组、字符串与结构体 |
| [lab02](lab02/) | C 编译、调试、内存与向量练习 |
| [lab03](lab03/) · [lab04](lab04/) | RISC-V 汇编练习 |
| [lab05](lab05/) · [lab06](lab06/) | 数字电路文件与配套测试 |
| [lab07](lab07/) | C、OpenMP 与配套测试 |
| [tools](tools/) | 课程工具下载脚本 |

## 使用

```bash
git clone https://github.com/ac0033/sp26-lab.git
cd sp26-lab
```

按对应实验的课程说明准备工具并运行测试。不同实验需要的 C、RISC-V 或电路工具不同，仓库没有一个覆盖所有实验的统一运行命令。

课程来源：[61c-teach/sp26-lab-starter](https://github.com/61c-teach/sp26-lab-starter)。原始材料的版权与使用要求以课程及文件中的声明为准。
